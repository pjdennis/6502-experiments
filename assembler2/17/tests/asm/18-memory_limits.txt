---
NAME: scope_stack_at_limit
DESCRIPTION: 51 nested macros assemble cleanly. Pre-Phase-3.4 this was at the SCOPE_STACK limit (51 entries x 5 bytes = 255 of 256 available); after the source-stack merge each macro's activation state lives in its memory frame's payload, so the limit is simply source-stack OOM. 51 is well within that.
INPUT:
 1: * = $0200
 2:   .include scope/s51.asm
EXPECT_HEX: ea

---
NAME: scope_stack_52_no_longer_overflows
DESCRIPTION: Post-Phase-3.4 there is no separate scope stack to overflow -- 52 nested macros assemble fine. Pre-Phase-3.4 this hit err_macro_nesting_too_deep (error 34); now that error code is unreachable for this scenario. A real deep-nesting OOM test wants many more levels and a small-heap setup; left for Phase 3.9.
INPUT:
 1: * = $0200
 2:   .include scope/s52.asm
EXPECT_HEX: ea

NAME: macro_same_name_as_label
DESCRIPTION: A macro and a global label can have the same name since they are in separate scopes (LABEL_TYPE_MACRO_DEF vs global)

 4:   LDA #val
 5:   .endmacro
 6:   test $55
 7:   LDA #test
EXPECT_HEX: a9 55 a9 42
